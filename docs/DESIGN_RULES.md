# Design rules
Direction: "quiet glass, one loud moment". Calm, precise, spacious, like macOS/visionOS settings meets a pro project tool. Spend boldness in ONE place (the 3D login hero); everything else is disciplined. Every spacing, radius, duration and color is a named token.

Color tokens (light / dark):
canvas #F5F5F7 / #000000; surface #FFFFFF / #1C1C1E; surface-raised #FFFFFF / #2C2C2E; ink #1D1D1F / #F5F5F7; ink-secondary #6E6E73 / #A1A1A6; accent #0071E3 / #2997FF (primary actions, focus, selection only); hairline rgba(0,0,0,.08) / rgba(255,255,255,.12).
Status (always icon + text label, never color alone): To do #8E8E93, In progress #0A84FF, In review #FF9F0A, Done #30D158.
Priority: High #FF453A, Medium #FF9F0A, Low #8E8E93. Project health: On track green, At risk amber, Overdue red.
Light and dark from the start. Theme switch is a 300ms cross-fade with no brightness flash.

Typography: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", then Inter variable as fallback, font-optical-sizing: auto. Sizes in rem. Size-specific tracking:
display 56/1.05 -0.03em 600 (login hero only); title-1 34/1.12 -0.022em 700; title-2 24/1.2 -0.018em 600; headline 17/1.3 -0.01em 600; body 15/1.5 0; caption 12/1.4 +0.01em.
Sentence case. No all-caps labels, no eyebrow labels above headings, no single accented word in headlines, no arrows appended to buttons.

Shape and depth: radius scale by hierarchy: chip 8, control 10, card 16, sheet 24, window 28; `corner-shape: squircle` as progressive enhancement in @supports. Layered, context-aware shadows (light on chips, deeper on sheets and lifted cards). Materials: sidebar, toolbar, sheets, popovers are translucent (backdrop-filter: blur(20px) saturate(180%) plus a 1px bright top edge); content scrolls under the toolbar with a scroll-edge fade, not a hard divider. Never stack a light translucent surface on another. Bigger surfaces get stronger blur and deeper shadow. Modal tasks use a dimming scrim; parallel panels (task drawer) do not. Honor prefers-reduced-transparency (solid, no blur) and prefers-contrast: more (near-solid with defined borders). 8pt spacing grid, content max-width 1280. No gradient wash cards; do not chop everything into identical rounded cards.

Motion: gate every animation by frequency and purpose first. If it fails the gate, ship no animation.
Tokens: --ease-out cubic-bezier(0.23,1,0.32,1); --ease-in-out cubic-bezier(0.77,0,0.175,1); --ease-drawer cubic-bezier(0.32,0.72,0,1). Durations: press 100-160ms, tooltip 125-200ms, dropdown/popover 150-250ms, sheet/modal 200-500ms; UI stays under 300ms except sheets and the login hero. Springs: default critically damped (bounce 0, duration 0.4); bounce 0.2 only after a flick.
Hard rules: animate only transform and opacity; in Motion use the full `transform` string, not x/y/scale shorthands. Never `transition: all`, never scale(0) (enter from scale(0.96) + opacity 0), never ease-in on UI. Popovers/dropdowns use transform-origin at the trigger; modals stay centered. Toasts, toggles and rapidly fired things use CSS transitions, not keyframes. Exit along the path of entry. Respond on pointer-down. Buttons: :active scale(0.97), 100ms ease-out. Hover effects only inside @media (hover: hover) and (pointer: fine). prefers-reduced-motion ships with every animation (swap slides and springs for 200ms opacity cross-fades; fewer and gentler, not zero). Stagger entering lists 30-80ms, max 8 items.
Per surface: command palette, sidebar nav, row hover = no animation or color-only 100ms. Route change = 200ms opacity cross-fade only. Progress rings/bars animate once on mount and on value change (transform, 400ms ease-out); charts otherwise static. Task marked Done = checkmark draws in 200ms plus one subtle ring pulse, no confetti. Project created and milestone approved are the only rare delight moments (soft scale-and-settle plus toast).

3D: only on the login hero, lazy-loaded with a static poster fallback (no WebGL, reduced motion, low-power). DPR capped at 2, pause when tab hidden. Everywhere else depth comes from CSS only.

Quality bar: WCAG 2.2 AA (semantic landmarks and headings, 4.5:1 text contrast, 3:1 large text and UI, visible :focus-visible rings, full keyboard operability including a drag-and-drop alternative, aria-live for status changes, labeled inputs, 44px touch targets, no info by color alone). Responsive mobile-first at 375, 768, 1024, 1280, 1536, no horizontal scroll. Performance: LCP under 2.5s, CLS under 0.1, INP under 200ms, route-level code splitting, virtualize long lists, no layout-triggering animation. Code: feature-based folders (app/, features/{auth,projects,teams,tasks,faculty}/, components/ui/, lib/, services/, mocks/, styles/tokens.css), strict TypeScript, no `any`, ESLint + Prettier, zod schemas shared with types, error boundaries per route, short prop comments. Resilience: optimistic updates with rollback, debounced search, form state preserved on navigation, 404 and permission-denied pages.
